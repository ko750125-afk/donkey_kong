# 🦍 동키콩 (Donkey Kong, 1981) — 아케이드 클론 PWA

> **"How high can you get? (여기까지 올라올 수 있을까?)"**  
> 1981년 닌텐도 아케이드 오리지널 《동키콩(Donkey Kong)》의 나무위키 문서 고증을 완벽하게 재현한 **오프라인 지원 PWA(Progressive Web App)** 게임입니다.

---

## ✨ 주요 특징 및 원작 고증 포인트

1. **오리지널 아케이드 4대 스테이지 완벽 수록** *(패미컴판에서 용량 문제로 삭제되었던 50m 스테이지 포함)*
   - **STAGE 1 (`25m` - 철골 공사장)**: 지그재그 경사 철골, 시작 직후 동키콩이 직선으로 던지는 **휘발유통(파란 통)**과 `OIL` 드럼통 점화, 사다리를 타고 내려오거나 직격으로 날아오는 **나무통**, **방해꾼 벌레(불씨)**.
   - **STAGE 2 (`50m` - 컨베이어 벨트)**: 방향이 수시로 바뀌는 컨베이어 벨트, 벨트 위를 흐르는 **시멘트**, 중앙 화로에서 솟아나는 불씨, 신축 사다리.
   - **STAGE 3 (`75m` - 엘리베이터)**: 상하로 순환하는 2열 엘리베이터 발판, 좌측 상단에서 `"띠용~"` 소리와 함께 통통 튀며 낙하하는 **스프링** 장애물.
   - **STAGE 4 (`100m` - 철근 나사 뽑기)**: 총 **8개의 노란 철근 나사(리벳)**를 모두 밟아 뽑으면 중앙 철골이 무너지며 **클래식 동키콩이 거꾸로 추락**하고 레이디(폴린)와 재회하는 엔딩 연출!
2. **캐릭터 & 아이템 세밀 고증**
   - **점프맨 (초기 마리오)**: 후대 마리오와 배색이 반대인 **파란 셔츠 + 빨간 멜빵**, 특유의 아케이드 보행 효과음, 높은 곳에서 떨어질 때의 **낙사 판정** 구현.
   - **무적 해머 (Hammer)**: 획득 시 유명한 **「해머 상태」 팡파레 BGM** 재생! 해머 사용 중에는 **점프 및 사다리 탑승이 불가능**하며 직진 타격만 가능(위쪽/뒤쪽 본체 피격 시 리타이어되는 원작 고증 반영).
   - **폴린의 소지품 (점수 아이템)**: 양산(Parasol), 모자(Hat), 핸드백(Purse) 획득 시 보너스 점수 부여.
   - **점프 회피 보너스**: 나무통·시멘트·불꽃을 점프로 뛰어넘으면 **100점**(2개 이상 동시 점프 시 **300점**).
3. **완전한 PWA (Progressive Web App) 지원**
   - `manifest.json` 및 `sw.js`(Service Worker) 탑재로 **PC 바탕화면 및 스마트폰 홈 화면에 앱으로 설치** 가능.
   - 네트워크 연결이 끊긴 **오프라인 상태에서도 100% 플레이 가능**.
   - 모바일/태블릿 환경에서 즉시 조작 가능한 **가상 아케이드 조이스틱(D-Pad + JUMP)** 탑재.

## 🎮 조작 방법

| 동작 | 키보드 조작 | 모바일 / 터치 조작 |
| :--- | :--- | :--- |
| **좌 / 우 이동** | `←` / `→` 또는 `A` / `D` | 좌측 하단 D-Pad `◀` / `▶` |
| **사다리 오르내리기** | `↑` / `↓` 또는 `W` / `S` | 좌측 하단 D-Pad `▲` / `▼` |
| **점프 (JUMP)** | `Space` 또는 `Z` | 우측 하단 빨간색 `JUMP` 버튼 |
| **게임 시작 / 재시작** | `Enter` 또는 `Space` | 화면 상단/하단 `START` 버튼 |
| **일시정지 (PAUSE)** | `P` | 상단 `PAUSE` 버튼 |
| **스테이지 즉시 이동 (테스트용)** | 숫자키 `1`(25m), `2`(50m), `3`(75m), `4`(100m) | 상단 스테이지 선택 버튼 (`25m`~`100m`) |
| **사운드 켜기 / 끄기** | `M` | 상단 `🔊 BGM` 버튼 |

## 🚀 실행 및 PWA 설치 방법

### 1. 로컬 웹 서버로 실행 (PWA 설치 및 서비스 워커 활성화 권장)
```bash
# Node.js 환경
npm start

# 또는 Python 내장 서버 사용 시
npm run dev
```
실행 후 브라우저에서 `http://localhost:3000` 에 접속하여 상단의 **`📲 앱 설치 (PWA)`** 버튼을 클릭하면 독립 실행형 아케이드 앱으로 설치됩니다.

### 2. 파일 직접 실행
별도의 서버 없이 `index.html` 파일을 더블클릭하여 브라우저에서 바로 열어도 모든 게임 플레이와 사운드가 정상 작동합니다.
